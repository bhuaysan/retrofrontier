# ADR-010: GPL-3.0-or-later project license
- Status: Accepted

## Context
RetroFrontier is intended to be open source.

## Decision
License RetroFrontier under `GPL-3.0-or-later`. Add a standard repository `LICENSE` file before public distribution. Third-party licenses remain independent and must be tracked.

## Consequences
Clear copyleft intent; dependencies/components require license compatibility and attribution review.
